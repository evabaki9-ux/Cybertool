Good to know

read-only
  • nmap when available: the app calls nmap -sV --open -oX - and reads its XML output. If nmap is missing, a TCP connect scan with banner grabbing is used instead.
  • Matches are hints: a version-based signature is not proof that a host is vulnerable. Confirm each result manually before acting on it.
  • Scope: only authorized systems. No credential guessing, payloads or exploitation is performed.
